# Personal Portfolio Website
A full-stack personal portfolio website to showcase my projects, skills, and experience.

## Features
- Responsive frontend built with HTML, CSS, JavaScript
- Backend using Flask / Node.js
- Database integration for project storage
- Contact form functionality
- Deployed on hosting platform

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Flask 
- Database: MongoDB

## Deployment
Deployment: Render
